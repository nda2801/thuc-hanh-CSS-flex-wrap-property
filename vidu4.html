CSS Flexbox Series
Từ khóa CSS chuẩn hóa

flex-wrap: initial

Từ khóa initial trong CSS có tác dụng đưa giá trị của một thuộc tính trở về giá trị mặc định gốc (initial value) được quy định bởi chuẩn W3C. Đối với flex-wrap, giá trị mặc định chính là nowrap.

Trạng thái tính toán thực tế của trình duyệt (Computed Style):
flex-wrap: nowrap
Item 1nowrap default
Item 2nowrap default
Item 3nowrap default
Item 4nowrap default
Item 5nowrap default
Item 6nowrap default

💡 Ý nghĩa kỹ thuật của từ khóa initial:

• Khi bạn áp dụng flex-wrap: initial, trình duyệt sẽ tra cứu thông số kỹ thuật W3C CSS Flexible Box Layout Specification. Tại bảng thông số, dòng "Initial: nowrap" quy định rằng container sẽ không tự bọc dòng.
• Khác biệt với inherit: inherit nhận lại giá trị từ phần tử cha (parent element), trong khi initial bỏ qua cha và đặt lại đúng giá trị ban đầu theo chuẩn W3C.
• Thường dùng khi muốn reset lại kiểu dáng bị ghi đè bởi framework CSS hoặc class cha. 

/* CSS áp dụng cho Flex Container */
.flex-container {
    display: flex;
    flex-wrap: initial; /* Trình duyệt tự giải quyết thành: nowrap */
    gap: 12px;
}

.flex-item {
    flex: 0 0 160px;
    height: 90px;
}
