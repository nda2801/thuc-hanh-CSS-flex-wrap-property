Giá trị mặc định

flex-wrap: nowrap

Khi sử dụng flex-wrap: nowrap, tất cả các flex item được xếp trên một dòng duy nhất. Nếu tổng độ rộng vượt quá container, các item sẽ co lại hoặc tràn viền (overflow).

💡 Quan sát hiện tượng:

Kéo thanh trượt "Độ rộng container" sang trái (thu hẹp) để xem kết quả:
• Khi shrink: 1 (mặc định): Các flex item tự động ép hẹp lại để vừa vặn trong 1 hàng duy nhất.
• Khi shrink: 0: Các item giữ đúng 160px và sẽ tràn ra khỏi container (hiện thanh cuộn ngang), tuyệt đối không bao giờ tự xuống dòng. 

/* CSS áp dụng cho Flex Container */
.flex-container {
    display: flex;
    flex-wrap: nowrap; /* Không cho phép xuống dòng (mặc định) */
    gap: 12px;
}

.flex-item {
    flex: 0 1 160px; /* flex-grow: 0, flex-shrink: 1, flex-basis: 160px */
}
