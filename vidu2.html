CSS Flexbox Series
Bọc xuống dòng tự động

flex-wrap: wrap

Khi không gian trên hàng hiện tại không còn đủ chứa item tiếp theo, flex-wrap: wrap sẽ tự động bọc các flex item sang dòng mới theo chiều từ trên xuống dưới (theo trục chéo Cross Axis).

💡 Tính năng nổi bật & Mẹo chuyên gia:

1. Tự động tính toán số cột: Với item rộng 160px + gap 12px, container 600px chứa được đúng 3 item/hàng. Các item tiếp theo tự động nhảy xuống hàng 2.
2. Sức mạnh của align-content: Thuộc tính align-content chỉ phát huy tác dụng khi flex container có nhiều dòng (nhờ flex-wrap: wrap). Bạn hãy thử đổi align-content ở menu phía trên để thấy cách các hàng được phân bổ không gian dọc! 

/* CSS áp dụng cho Flex Container */
.flex-container {
    display: flex;
    flex-wrap: wrap; /* Cho phép bọc sang nhiều dòng */
    align-content: flex-start; /* Căn chỉnh các dòng dọc trục chéo */
    gap: 12px;
}

.flex-item {
    flex: 0 0 160px; /* Giữ cố định kích thước 160px để quan sát bọc dòng */
    height: 90px;
}
