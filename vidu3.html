CSS Flexbox Series
Đảo ngược hướng bọc dòng

flex-wrap: wrap-reverse

Đảo ngược chiều của trục chéo (cross-axis). Các flex item vẫn xếp từ trái qua phải theo main axis, nhưng dòng mới được xếp ngược lên trên (dòng 1 nằm ở dưới đáy, dòng 2 nằm ở trên).

600px
Item 1Hàng 1 (Dưới)
Item 2Hàng 1 (Dưới)
Item 3Hàng 1 (Dưới)
Item 4Hàng 2 (Trên)
Item 5Hàng 2 (Trên)
Item 6Hàng 2 (Trên)

💡 Quan sát phân tích hướng luồng (Flow Direction):

• Với container rộng 600px, Item 1, 2, 3 xuất hiện ở hàng DƯỚI CÙNG.
• Khi hết không gian, Item 4, 5, 6 tự động bọc lên hàng PHÍA TRÊN.
• Thuộc tính này cực kỳ hữu ích khi bạn muốn tạo các luồng tin nhắn chat (tin mới đẩy từ dưới lên), menu nổi dạng ngăn kéo (bottom drawer) hoặc biểu đồ xếp chồng ngược. 

/* CSS áp dụng cho Flex Container */
.flex-container {
    display: flex;
    flex-wrap: wrap-reverse; /* Bọc dòng ngược hướng trục phụ */
    gap: 12px;
}

.flex-item {
    flex: 0 0 160px;
    height: 90px;
}
